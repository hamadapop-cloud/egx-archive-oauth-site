Privacy & data handling

Privacy policy

Effective date: November 18, 2026. Applies to the EGX Archive personal desktop/automation integration using Google Drive and to this informational website.

1. Purpose and operator

EGX Archive is an independently operated personal utility to archive eligible publicly accessible Egyptian stock-market files in the owner's own Google Drive. It is not an official product of the Egyptian Exchange, Google or GitHub and is not marketed as a public service.

2. Google account permissions

EGX Archive uses OAuth 2.0 and rclone to access Google Drive. Its current Google Drive scope is https://www.googleapis.com/auth/drive, which can technically allow reading, creating, modifying and deleting files throughout the authorized account's Drive. The intended workflow instead operates on the configured archive location. This distinction is important: Google's permission is broader than the workflow's intended access pattern.

3. Data processed

The application processes public source files, archive manifests, file identifiers, checksums, dates, diagnostic results and workflow state. Google OAuth access and refresh tokens are held in the owner's rclone configuration and may be supplied to the private GitHub Actions workflow through an encrypted repository secret; tokens are not published on this website. The service is not designed to collect unrelated personal Google Drive documents.

4. Use and storage

Data is used to identify eligible files, check integrity, avoid accidental duplication, and keep archived copies and technical diagnostics. Archive objects are kept in the owner's Google Drive. GitHub Actions processes files during scheduled jobs and may retain technical execution logs under GitHub's retention settings. Google and GitHub act as infrastructure providers according to their respective policies.

5. Sharing, advertising and tracking

The application is not designed to sell, advertise with, or publicly distribute information obtained through Google Drive OAuth. This static informational site does not include analytics scripts or advertising trackers. Standard requests to GitHub Pages may still be logged by its hosting provider. Do not submit secrets or account data through public GitHub issues.

6. Retention and deletion

Archived files remain in the owner's Google Drive until the owner deletes them. The owner can remove archived files from Drive, disable the GitHub workflow, delete its encrypted secret and revoke EGX Archive's authorization from Google Account permissions. Revocation stops future Drive access using the revoked authorization but does not automatically delete files already archived or historic GitHub workflow logs.

7. Security and limitations

The workflow is intended to keep OAuth credentials in private configuration/secrets and not in public source code or public pages. No computer system guarantees zero risk. GitHub and Google maintain their own access controls and data-handling terms. The account owner is responsible for reviewing granted permissions and access.

8. Changes and contact

This policy may be updated if functionality or data handling changes. The effective date above will be updated accordingly. For questions, use the developer support address displayed in the Google consent screen or open an issue on the public site repository without including private data.

ملخص بالعربية

يستخدم EGX Archive صلاحية Google Drive لحفظ ملفات عامة وأدلة أرشفتها في حساب المالك. نطاق الصلاحية الممنوحة من Google أوسع من مجلد الأرشيف المحدد. تحفظ رموز الدخول في إعدادات خاصة وأسرار GitHub Actions وليست على الموقع العام. يستطيع المالك إلغاء السماح من إعدادات حساب Google وحذف الملفات من Drive بنفسه.
